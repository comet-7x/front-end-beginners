# 阶段 5：Node.js 服务端架构与数据库 (Full-Stack TS Backend)

> **本阶段目标**：掌握服务端体系，使用 TypeScript + Hono / NestJS 构建带用户鉴权、数据库持久化和输入校验的 RESTful API。

---

## 规划模块

1. `01-node-core/`：Node.js 运行时核心机制、事件循环、Buffer、Stream 流与 HTTP 模块
2. `02-rest-api-hono/`：基于 Hono / Express 构建现代 RESTful API 与中间件流水线
3. `03-database-prisma/`：PostgreSQL / SQLite 数据库设计、数据迁移与 Prisma ORM
4. `04-auth-and-security/`：JWT 身份认证、密码哈希 (bcrypt)、CORS、安全防护
