# 阶段 3：TypeScript 核心与全栈类型思维

> **本阶段目标**：掌握静态类型系统建模，掌握泛型与类型收窄，跨越“从 JS 到 TS”的思维鸿沟，为前端框架与全栈 API 提供类型契约保护。

---

## 规划模块

1. `01-basic-types/`：类型注解、原始类型、字面量类型、any vs unknown vs never
2. `02-interfaces-and-types/`：interface vs type 选型、可选与只读、索引签名
3. `03-generics-and-narrowing/`：泛型函数与接口、泛型约束 (`extends`)、类型收窄
4. `04-type-gymnastics/`：常用工具类型原理解析 (Partial, Pick, Omit, Record) 与 Type-Challenges 基础关卡
5. `05-fullstack-contracts/`：前后端类型共享与 Zod 运行时 Schema 校验实战
