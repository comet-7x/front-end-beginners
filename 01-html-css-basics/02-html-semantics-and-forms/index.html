为什么现代 Web 强调「语义化 (Semantics)」？

2026年10月13日

在早期的 Web 开发中，很多人习惯用 <div class="header">、<div class="nav"> 来写页面，这被称为「div 汤 (div soup)」。

现代 HTML5 引入了语义化标签，主要带来三大核心价值：

  1. 可访问性 (a11y)：视障用户使用屏幕朗读器时，可以通过快捷键直接跳到 <main> 或 <nav>。
  2. 搜索引擎优化 (SEO)：爬虫更容易提取权重高的标题和核心正文。
  3. 代码可读性与团队维护：结构清晰，见名知意，远离无意义的嵌套。

“HTML 是 Web 的基础骨架。好的骨架让样式 (CSS) 和逻辑 (JS) 的编写水到渠成。”

💡 知识卡片：块级元素 vs 行内元素

块级元素 (Block)：如 <h1>, <p>, <div>, <section>。独占一行，默认宽度撑满父元素，可设置宽高。

行内元素 (Inline)：如 <span>, <a>, <strong>, <code>。依附在文本流中，不换行，设置宽高无效。
