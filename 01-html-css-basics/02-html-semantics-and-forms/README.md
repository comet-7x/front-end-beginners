# HTML5 核心与语义化结构指南

> **核心认知**：你的理解非常精准——**HTML 负责页面骨架与内容语义，CSS 负责外观表现，JS 负责动态交互**。
>
> 就像建造一栋大厦：
> - **HTML** 是钢筋混凝土主体框架（墙壁、门窗、楼层）。
> - **CSS** 是室内装潢与外墙粉刷（油漆颜色、瓷砖材质、灯光与布局排版）。
> - **JS** 是智能家居与水电路网（点击开关灯亮、感应门自动开启、数据实时通信）。

---

## 1. HTML 文档解剖学 (The Anatomy of HTML)

打开一个标准 HTML 文档，它由三个关键部分构成：

```html
<!DOCTYPE html>              <!-- 1. 文档声明：采用 HTML5 标准模式渲染 -->
<html lang="zh-CN">          <!-- 2. 根元素：包裹整篇网页内容，指定语言 -->
  <head>                     <!-- 3. 元信息区：不直接展示给用户，供浏览器和搜索引擎读取 -->
    <meta charset="UTF-8" />  <!-- 字符编码（UTF-8 杜绝乱码） -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0" /> <!-- 移动端适配关键 -->
    <title>网页标题</title>   <!-- 浏览器标签栏文本 -->
  </head>
  <body>                     <!-- 4. 视口可见区：用户在屏幕上看到的所有内容 -->
    <h1>页面主标题</h1>
  </body>
</html>
```

## 2. 现代 HTML5 语义化标签图解

传统的无语义写法（容易沦为不可维护的“div 汤”）：
```html
<div id="header">...</div>
<div id="nav">...</div>
<div id="content">
  <div class="post">...</div>
  <div class="sidebar">...</div>
</div>
<div id="footer">...</div>
```

**现代 HTML5 语义化标准结构**：
```text
┌───────────────────────────────────────────────┐
│  <header> 页眉 (网站 Logo、主标题)              │
├───────────────────────────────────────────────┤
│  <nav> 核心导航栏 (首页、博客、关于我们)          │
├───────────────────────────────────────┬───────┤
│  <main> 页面核心主体                  │<aside>│
│  ┌──────────────────────────────────┐ │侧边栏 │
│  │ <article> 独立文章内容            │ │相关推荐│
│  │   <section> 章节一 </section>     │ │广告/链接│
│  │   <section> 章节二 </section>     │ │     │
│  └──────────────────────────────────┘ │       │
├───────────────────────────────────────┴───────┤
│  <footer> 页脚 (版权声明、备案信息、法律条款)    │
└───────────────────────────────────────────────┘
```

### 为什么必须掌握语义化？
1. **搜索引擎优化 (SEO)**：百度、Google 等爬虫能根据 `<main>`、`<article>`、`<h1>` 等精确提取页面核心权重，提升排名。
2. **无障碍访问 (Accessibility / a11y)**：视障人群使用屏幕朗读器时，可以按快捷键直接跳转至 `<nav>` 或 `<main>`，提升产品可用性。
3. **团队协作与可维护性**：阅读代码一目了然，不需要给每个容器猜 class 名字。

## 3. 块级元素 (Block) vs 行内元素 (Inline)

这是后续**掌握 CSS 盒模型与布局（Flex/Grid）的最底层基石**：

| 类型 | 典型标签 | 排版表现 | 宽高设置 |
| :--- | :--- | :--- | :--- |
| **块级元素 (Block)** | `<div>`, `<p>`, `<h1>`~`<h6>`, `<ul>`, `<form>`, `<header>` 等语义标签 | **独占一行**（前后自动换行），默认宽度为父容器的 100% | 支持通过 CSS 自由设置 `width` 和 `height` |
| **行内元素 (Inline)** | `<span>`, `<a>`, `<strong>`, `<em>`, `<code>` | **并排显示**（不换行，依附在文本流中），宽度由内容自然撑开 | **无法直接设置宽高**（`width/height` 无效），上下 margin 无效 |

## 4. 表单系统 (Forms) —— 全栈数据交互的门户

全栈开发的核心就是**数据在前端页面与后端服务器之间的流转**，而表单就是用户输入数据的核心入口：

- `<form action="/api/login" method="POST">`：定义数据提交的目标地址和 HTTP 动词。
- `<label for="email">`：关联对应 input，点击文字可直接聚焦到输入框。
- 常用 input 类型：
  - `type="text"`：常规单行文本
  - `type="password"`：密文输入框
  - `type="email"`：自带邮箱格式验证
  - `type="number"`：数值（可配合 `min`, `max`, `step`）
  - `type="checkbox"`：多选框
  - `type="radio"`：单选框（相同 `name` 的选项互斥）
  - `type="file"`：文件上传
