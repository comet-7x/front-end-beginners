# 阶段 1：HTML5 与现代 CSS3 响应式设计基石

> **本阶段目标**：掌握 HTML5 语义化结构搭建，彻底搞懂现代 CSS 盒模型、Flexbox 弹性盒与 CSS Grid 网格布局，能够独立实现适配桌面与移动端的自适应页面。

---

## 目录结构

- `01-first-website/`：基于 MDN 入门指南构建的首个网页（已包含基础 HTML 标签、CSS 美化与脚本挂载）
- `02-flexbox-and-grid/`：现代弹性盒与网格布局实战案例（即将演练）
- `03-responsive-landing/`：响应式移动端与 PC 端自适应实战（即将演练）

---

## 阶段 1 核心自查清单

- [ ] **语义化标签**：理解 `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>` 各自适用的场景。
- [ ] **标准盒模型**：清楚 `box-sizing: content-box` 与 `box-sizing: border-box` 的区别（为什么现代 CSS 几乎统一使用 `border-box`）。
- [ ] **Flexbox 核心轴线**：理解 `flex-direction`、主轴对齐 `justify-content` 与交叉轴对齐 `align-items`。
- [ ] **CSS Grid 二维排版**：使用 `grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))` 制作自适应卡片流。
- [ ] **响应式断点**：理解 Mobile-First（移动优先）设计思维与 `@media (min-width: ...)` 媒体查询。
