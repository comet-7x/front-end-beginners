# 阶段 4：现代前端双框架（Vue 3 & React 19）实战与架构对比

> **本阶段目标**：掌握两大当今最核心的主流前端框架。通过对比 Vue 的“响应式数据代理”与 React 的“单向数据流与快照渲染”，建立框架之上的架构抽象能力。

---

## 规划模块

1. `vue3-playground/`：Vue 3 + Vite + Pinia + Vue Router + Element Plus / Tailwind
2. `react19-playground/`：React 19 + Vite + Zustand + TanStack Query + Tailwind / shadcn/ui
3. `architecture-comparison.md`：核心响应式原理与心智模型横向对比笔记
